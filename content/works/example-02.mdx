# AI 影像实验 #01

探索 AI 工具在视觉创作中的可能性。

## 实验目标

本次实验旨在探索：
1. AI 生成影像作为创作起点的可行性
2. 人机协作的创作工作流
3. AI 影像的审美边界

## 工作流程

1. **构思与 Prompt 设计** — 手工设计视觉概念与对应的 Prompt
2. **生成与筛选** — 从大量生成结果中筛选符合审美的作品
3. **后期精修** — 使用传统工具对 AI 输出进行精细调整
4. **叙事构建** — 将单张影像组织为系列叙事

## 技术栈

- Stable Diffusion + 自训练 LoRA
- Photoshop 后期
- 人工筛选与策展
